## 项目概览

- **项目名称**：数据管理系统
- **核心描述**：基于 Django 的旅游平台评论数据管理系统，负责采集、管理、分析并可视化多平台评论数据。
- **主要模块**：
  - `spiders`：评论数据管理与配置管理
  - `accounts`：用户认证与权限控制
  - `spider_management`：全局配置

## 技术栈

- Python 3.9+
- Django 3.2.24
- MySQL 5.7+
- 前端：HTML5 / CSS3 / JavaScript / Bootstrap 5
- 可视化：Chart.js

## 当前任务状态

- `STATE` 目录用于记录正在进行的任务状态。
- 初始状态：尚未记录活动任务。

## 文档约定

- `.docs/` 为项目的单一事实来源（SSoT）。
- 所有规则存放于 `.docs/RULES/`。
- 任务执行过程和状态记录存放于 `.docs/STATE/`。
